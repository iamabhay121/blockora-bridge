# Guides

**Blockora Bridge** is a testnet workspace for Hedera and Ethereum: create accounts, issue tokens/NFTs, send assets, manage approvals, and review transactions.

In the app, open the **Guides** button (bottom-right) and pick:

- **[User guide](docs/USER_GUIDE.md)** — step-by-step for using Hedera and Ethereum features
- **[Developer guide](docs/DEVELOPER_GUIDE.md)** — setup, contracts, scripts, and architecture

Or read those files directly in this repo.
